# Фото-опись комплектующих и серийных номеров при вскрытии техники: Telegram-бот, n8n, Ollama (vision) и PostgreSQL (Docker Compose, Cloudflare Tunnel)

Набор к ролику «Фото-опись плат при вскрытии техники в сервисном центре». Инженер присылает в Telegram-бот фото материнской платы с номером заказ-наряда, локальная нейросеть Ollama с vision-моделью читает серийные номера, n8n считает SHA-256 фото, шифрует снимок и пишет запись в PostgreSQL с точным временем (UTC). Выходит технический акт описи с фотофиксацией, SHA-256 хешем и временем для защиты от споров. Без абонентской платы за сервис: платите за сервер.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep50-service-audit && cd ep50-service-audit
```

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose; туннель и домен в Cloudflare Zero Trust (маршрут на `http://n8n:5678`); бот у @BotFather.
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32` (пароль базы, ключ n8n, ключ шифрования фото), впишите домен и токен туннеля.
3. `docker compose up -d`, затем `docker compose exec ollama ollama pull qwen2.5vl:7b` (модель из `OLLAMA_VISION_MODEL`, пример), откройте `https://ваш_домен` и создайте администратора n8n.
4. В n8n импортируйте `service_audit_n8n.json`, создайте учётные данные Telegram и PostgreSQL, активируйте сценарий.
5. Отправьте боту фото платы с подписью `ZN-1042`, получите акт, проверьте `SELECT verify_audit_chain();` (0 = цепочка цела).

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек и сценарий на живом сервере и в живом n8n **не запускал**, SQL-схему на живом PostgreSQL не исполнял. Проверены только логика узлов Code в Node и шифрование с расшифровкой скриптом. Теги образов (`latest`), узлы Telegram, Postgres, записи файла, отправки документа и поведение Ollama сверьте с документацией ваших версий.
- Хеш SHA-256 подтверждает, что файл не менялся после записи. Он не доказывает подлинность момента съёмки и не защищает от администратора базы с полным доступом. Юридическую значимость акта, согласие клиента на съёмку при приёмке, хранение фото и серийных номеров (152-ФЗ) и срок хранения проверьте у юриста. Это не юридическая консультация.
- Точность распознавания мелких серийных номеров vision-моделью не проверялась; низкая уверенность помечается «проверить глазами».
- Ключ шифрования фото храните отдельно от сервера; потеряете ключ, снимки не расшифровать.
- Сумма 180 000 ₽, потеря 38 000 ₽ и цена внедрения 50-80 тыс. ₽ в ролике это сценарные примеры и оценки владельца. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Нужен бэкап базы по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление и расшифровка не проверены. Ночная выгрузка журнала в `backups` не заменяет полную копию.
